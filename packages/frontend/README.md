# Spotlight — Frontend

The Next.js frontend for Spotlight. Provides the user interface for the community platform including feeds, profiles, messaging, and admin settings.

## Scripts

| Command       | Description                        |
| ------------- | ---------------------------------- |
| `yarn dev`    | Start Next.js development server   |
| `yarn build`  | Create optimized production build  |
| `yarn start`  | Start production server on port 3000 |
| `yarn lint`   | Run ESLint                         |
