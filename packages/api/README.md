# Spotlight — API

The Express.js backend for Spotlight. Handles authentication, database operations, real-time Socket.io events, and REST API routes.

## Scripts

| Command       | Description                              |
| ------------- | ---------------------------------------- |
| `yarn dev`    | Start development server with hot reload |
| `yarn build`  | Compile TypeScript to `build/`           |
| `yarn start`  | Start production server                  |
| `yarn lint`   | Run ESLint                               |

## Environment Variables

Copy `.env.example` to `.env` and fill in your values. See the root [README](../../README.md) for details.
